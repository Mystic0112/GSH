gsh — GSH's internal CLI (visible only inside the app's terminals)

A **tab** is a terminal/agent session (what this CLI addresses). A **pane** is
the split leaf that groups tabs — not addressed here. `list-panes`/`read-pane`
are legacy aliases of `list-tabs`/`read-tab`.

USAGE:
  gsh msg --to <label|tab-id> [--json] <text>
                                               message another agent's tab
                                               (typed + Enter, signed with your tab)
  gsh send --to <Name/agent> [--json] <text>    knock on a teammate's agent over the LAN
  gsh send [--tab-id <id> | --focused] [--enter] <text>
                                               type text into a tab (--enter submits)
  gsh peers [--json]                          list linked and reachable agents
  gsh deliver --to <Name/agent> [--json] <file> [note]
                                               hand a file to a teammate's agent
  gsh open [--tab-id <id> | --focused] <file> open a file in the app's viewer
  gsh <file>                               shorthand for `gsh open <file>`
  gsh read-tab [<label|tab-id>] [--lines <n>] [--offset <n>] [--from-start]
                                               read a tab's rendered output (alias: read-pane)
  gsh rename-tab [<label|tab-id>] <title> [--json]
                                               rename a tab (prints its id)
  gsh interrupt [<label|tab-id>] [--force] [--json]
                                               interrupt a tab's running turn/process
  gsh wait-idle [<label|tab-id>] [--json]  wait until a tab returns to idle
  gsh localsend peers [--wait <s>] [--json]     list LocalSend devices on the LAN
  gsh localsend send <alias|ip> [--timeout <s>] <file...>
                                               send files to a LocalSend device
  gsh list-tabs       [--json]             list active tabs (alias: list-panes)
  gsh new-tab [--cwd <dir>] [--title <name>] [--split h|v] [--tab-id <id>] [--json]
                                               open a new terminal tab (prints its id)
  gsh close-tab [<label|tab-id>] [--json]  close a tab (default: the current
                                               one) — prints the closed tab id
  gsh telemetry <command>                 run observed or query the error store
                                               (see `gsh telemetry --help`)
  gsh browser <command>                    control the Obscura browser
  gsh mcp --agent <app-id>                  run GSH's MCP server over stdio
  gsh hook [--harness <name>]              lifecycle hook helper (reads the
                                               harness event JSON on stdin)
  gsh --help | --version

MSG:
  gsh msg --to Reviewer "diff ready in feat/x, please review"
  The target receives `[from: <your label or title> · <your harness>] <text>`
  and Enter. Sender = $GSH_TAB_ID (required). `list-tabs --json` shows each
  tab's detected `harness` (claudeCode, codex, antigravity, …) or null.

TEAM (office network):
  gsh send --to "Bianca/financeiro" "I changed the payments table, check your side"
  gsh deliver --to "Bianca/financeiro" report.pdf "weekly report"
  With the team farm on (same team name and password on both GSHs), a
  teammate's agent is addressed as `Name/agent`. The message knocks on
  their door: their agent receives it as information from a teammate (not an
  order from their user) and decides what to do; deliveries land in
  `.gsh/inbox/<your name>/` in their agent's folder. When a teammate knocks
  on yours, reply with the `gsh msg --to ...` line shown in the message.

LOCALSEND:
  gsh localsend peers [--json]
  gsh localsend send <alias|ip> <file...>
  Lists or sends files to LocalSend Protocol v2 devices. A transfer requires
  acceptance on the receiving device.

OPEN:
  Relative paths are resolved from your current directory. A terminal tab
  target opens the file in that tab's pane. With no target or --focused, the
  app uses its current pane. Success produces no output.

READ (read-tab):
  --lines N     how many lines (default 100, server cap 2000)
  --offset N    skip N lines from the anchor (pagination)
  --from-start  anchor at the start of the buffer (default: tail/end)
  Output is always chronological (top→bottom); flags only pick the window.
  read-tab without a target reads the CURRENT tab; a target may be a stable
  tab label or a tab-id.

BROWSER:
  install, start, stop, status, open, close, pages, goto, back, forward,
  reload, snapshot, click, fill, press, eval, text (alias: markdown), shot, wait
  Use --page <name> to select a page and --json for machine-readable output.

MCP:
  Supported app ids: claude-desktop, cursor, codex-desktop.

FLAGS:
  --enter         (send only) press Enter right after the text, as a separate
                  keystroke.
  --force, -f     (interrupt only) force immediate interruption.
  --focused       target the tab you are LOOKING AT, whatever it is. Resolved by
                  the app, so no id to copy. Works from outside a GSH
                  terminal too (dictation tools, scripts): with no env inherited
                  the CLI finds the app through ~/.gsh/status.sock.

TARGET:
  --tab-id <id>   target tab (--focused wins over it). Default = $GSH_TAB_ID
                  (the current tab;
                  legacy fallback $GSH_PANE_ID). Ids (t0, t1…) reset on every
                  app boot → find them with `gsh list-tabs` before targeting
                  another tab (cross-tab).

NEW-TAB:
  --cwd <dir>     working directory (default: current directory)
  --title <name>  stable tab label (msg and close-tab can target it by name)
  --split h|v     h (or right) = side by side; v (or down) = stacked.
                  Omit to open as a new tab in the same pane.
  Anchored at the emitting tab's pane/workspace unless --tab-id is set.
  Prints the new tab id. The --focused flag applies to open, close-tab and
  list-tabs.

CLOSE-TAB:
  gsh close-tab [<label|tab-id>]
  Without a target it closes the CURRENT tab — the shell you are typing in
  ends with it. Closing the last tab of a split removes the split; closing the
  last tab of a workspace leaves an empty tab (same as the tab's "x" in the UI).

EXAMPLES:
  gsh open ./README.md
  id=$(gsh new-tab --cwd ~/proj --title Worker --split h)
  gsh msg --to "$id" "run the tests"
  gsh close-tab "$id"                      # close it when done (or: Worker)
  gsh list-tabs --json
