# ADR 0001: stack de UI

Status: aceito para Linux. Windows e macOS em aberto.

## Contexto

O GSH está sendo reescrito de Flutter para Rust, com paridade de comportamento e aparência com a versão atual. A UI precisa ser leve (é a motivação da troca), personalizável e bonita (ilha animada, fazenda com sprites). Precisa rodar em Linux, Windows e macOS.

Candidatos avaliados: iced, gpui, egui, slint e Tauri (webview).

## Decisão

**Linux: iced 0.14.** A UI fica num crate próprio (`crates/app`), e o núcleo (`gsh-core`) continua sem dependência de UI.

Motivos:
- Render por wgpu na GPU. No teste em Linux com Intel Iris Xe, o iced usou a GPU.
- Consumo medido: ~115–117 MB de RAM e ~15–17% de um núcleo, com o grid de texto redesenhado a 60 fps.
- O COSMIC, desktop usado no Linux do projeto, é feito com iced (via libcosmic).
- Animações e sprites ficam em `canvas`, sem webview.

## Rejeitadas (por enquanto)

- **Tauri (webview):** o terminal e a fazenda rodam dentro de um navegador embutido. Mais RAM e tempo de inicialização. Descartado pelo critério de leveza.
- **gpui 0.2.2 no Linux:** no mesmo cenário, não iniciou a GPU Intel (`NoSupportedDeviceFound`) e caiu para software, com CPU de 90–257%. A causa não foi identificada.
- **egui:** serviria, mas o visual sai de ferramenta e não de app nativo.
- **slint:** a licença (GPLv3 ou pago) não serve para um produto fechado.

## Em aberto

- **Windows:** depende do teste com a RTX 3050 (card "[SPIKE] Comparar iced vs gpui no Windows"). Se o gpui usar a GPU NVIDIA com CPU baixa, ele pode ser reavaliado para Windows.
- **macOS:** proposta de UI nativa (SwiftUI/AppKit) chamando o core Rust por FFI. Não decidido. Se o gpui for a escolha no Mac, precisa de teste no Mac.

## Consequências

- Terminal: iced não tem widget de terminal. Ele será desenhado em `canvas`, depois que o spike de PTY e emulador (card "[F1] Spike do terminal") validar o caminho.
- Paridade visual com o Flutter: os widgets (layout, árvore de arquivos, abas) são reconstruídos, não copiados.
- Se o iced quebrar algo do COSMIC ou do render no Linux, este ADR é revisto.
